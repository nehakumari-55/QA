# Neha Kumari — QA Engineering Portfolio

A responsive single-page GitHub Pages portfolio for Neha Kumari, focused on Quality Assurance, Test Automation and Quality Engineering.

## Publish on GitHub Pages

1. Create a GitHub repository, for example `neha-kumari.github.io`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Personalization before publishing

- Replace or confirm any SAP/Fiori wording against your actual project experience.
- Add ISTQB only if you have completed the certification.
- Add project links, GitHub repositories, screenshots or case studies when available.
- Consider adding a professional headshot only if you want a personal visual identity.
